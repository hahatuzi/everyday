# 2026 大厂前端面试 · AI 相关题汇总

> 整理时间：2026-10-15
> 覆盖公司：字节 / 阿里 / 腾讯 / 快手 / 美团 / Shopee
> 覆盖轮次：一面 ~ 三面（含交叉面、HR 面偶发）

---

## 0. 趋势速览（先看这个再准备）

- **考察比例**：一二三面中至少一轮会问 AI，纯前端岗约 **40%~60%** 的面试会出现 AI 题（2024 年还不到 20%）
- **考察重点迁移**：
  - 2024：Transformer 架构 / Attention 公式 / 训练流程
  - 2026：**流式渲染、RAG、Agent、MCP、端侧 AI、AI 协作工具**
- **国产化必聊**：通义 / 文心 / 混元 / DeepSeek / Kimi 都要懂，不再只背 OpenAI
- **必带"作品"**：现场白板或要求 demo 的概率很高（>30%）

---

## 一、LLM 基础（几乎必问，1~3 题）

1. Transformer / Self-Attention 原理；为什么注意力要除以 √d_k
2. **Token 是什么**；为什么 1 个汉字 ≠ 1 个 token；中英文 token 比例差异
3. Embedding 是什么；语义检索为什么能"找相似"
4. **上下文窗口受限于什么**（计算量是 O(n²)）；长对话为什么会"前面忘"
5. 幻觉的成因 + 5 种缓解手段（RAG / CoT / Tools / 约束解码 / 多模型投票）
6. `temperature` / `top_p` / `top_k` 区别与场景 
7. SFT / RLHF / DPO 各自解决什么问题
8. LoRA / QLoRA 是什么，为什么能"低成本微调"
9. **KV Cache**、Prefill、Decode 阶段区别（与流式密切相关）
10. MoE（混合专家）结构与前端看不到的"性能-成本"权衡

> 答不出 KV Cache / 上下文窗口的**实现原理**，基本就过不了二面。

---

## 二、AI 客户端工程（前端的真正主场，占比最高）

1. **SSE vs WebSocket vs `fetch + ReadableStream`**，流式场景下怎么选
2. 如何用 `fetch` + `ReadableStream` 增量解析并渲染
3. `AbortController` 取消生成；取消后如何回滚乐观更新
4. **流式片段截断在 Markdown / 代码块 / 链接中的处理**（高频、区分度高）
5. 大段对话的渲染性能：`react-virtual` 虚拟列表的选型与陷阱
6. Markdown / HTML 渲染的 XSS 风险；如何防"提示词注入进 DOM"
7. 多模态：图片 / 音频 / 文件上传的预处理（压缩、base64 vs URL、PDF 解析）
8. **对话历史压缩**：滑动窗口、摘要压缩、Map-Reduce 压缩
9. **Token 成本估算** + 缓存（Prompt Cache / 语义缓存 / KV 复用）
10. 流式异常兜底：超时、断网、HTTP/2 stream 关闭、自动重连
11. 流式打字机效果的体验设计（光标、停顿、首字延迟优化 TTFT）
12. **结构化输出**（JSON / Function Call）在前端如何安全地解析与展示

> 这块是"前后端联合考察"题，必考。

---

## 三、AI 协作开发 / Vibe Coding（2025 后新兴热点）

1. 用过哪些 AI 编程工具？**Cursor / Copilot / Cline / Windsurf / Claude Code / Trae / 通义灵码** 各有什么特点
2. **Spec-driven**、AGENTS.md / CLAUDE.md 在团队里怎么落地
3. 怎么审查 AI 生成的代码（评审清单、单测覆盖率、diff review）
4. Vibe Coding 的风险（幻觉接口名、过期 API、漏边界）与治理
5. AI 生成 UI 后如何保证 **Design System 一致**（Token / Figma MCP / Style Dictionary）
6. 团队内部 **Rules / Prompt 模板** 如何设计
7. 你最近一次让 AI 重构 / 写组件 / 修 Bug 的实际例子
8. 怎么用 AI 写测试、写 PR 描述、Code Review

> 字节 / 美团几乎每场必问；不会用 AI 写代码的候选人会被认为"不拥抱变化"。

---

## 四、RAG / Agent / Function Calling

1. **RAG 完整链路**：文档分块 → 嵌入 → 检索 → 重排 → 生成；每一步的常见坑
2. 为什么需要 **Rerank**；与纯 Embedding 检索的差异
3. 文档分块策略：定长 / 段落 / 滑动窗口 / 语义切片
4. **Agent 循环决策**：ReAct、Plan-and-Execute、Reflexion
5. **Function Calling / Tool Use** 协议：OpenAI 格式 vs Anthropic 格式 vs Google 格式
6. **MCP**（Model Context Protocol）是什么，与 Function Call 的关系
7. **A2A**（Agent-to-Agent）协议，解决什么问题
8. 多 Agent 协作的工程实现（消息总线 / 状态共享 / 死锁）
9. Agent 异常处理：工具循环、幻觉、超时、幂等性
10. RAG 评估指标：Recall@k、答案忠实度、Context Precision / Recall

> MCP 是 2025 下半年到 2026 的**绝对高频题**，要能讲清"它就是 AI 时代的 USB-C 接口"。

---

## 五、端侧 AI（Web 端差异化，2026 新热点）

1. **WebLLM** / `transformers.js` / `MediaPipe LLM Inference` / `onnxruntime-web` 区别
2. **WebGPU** 与 WebNN，前端能跑多大的模型（一般 1B~8B，量化后）
3. **Chrome Built-in AI**（Prompt API / Gemini Nano）能力与限制（设备要求、是否要科学上网）
4. 量化：Q4 / Q5 / Q8 / FP16 / BF16 取舍
5. 端侧 embedding（gte-small / bge-small / all-MiniLM）做 RAG 的可行性
6. 跨端差异：iOS Safari / Android WebView 的 WebGPU 支持现状
7. 端侧推理的 **首 Token 延迟**（首帧几百 ms vs 云端几十 ms）的优化
8. Web Worker / OffscreenCanvas 与端侧模型的协同

> 阿里 / 字节 AI 产品线（豆包、通义、灵积）爱问；说明"我跑过 WebLLM 加载一个 1B 模型"会非常加分。

---

## 六、安全 & 合规（容易被忽略的加分项）

1. **提示词注入**（直接 / 间接 / 存储型）三类攻击与防御
2. 间接提示词注入：从文档 / 搜索结果 / 网页内容发起的攻击
3. 越狱现象与防护（系统提示词 + 输出过滤 + 工具白名单）
4. AI 生成内容标识：水印、**C2PA** 协议、中国《生成式 AI 服务管理暂行办法》要求
5. 数据合规：训练数据版权、用户数据隔离、模型微调数据脱敏
6. 跨境调用：国内合规备案、数据出境

---

## 七、系统设计 / 场景题（高级岗必出）

1. **设计一个"AI 客服对话"前端**：流式 + 取消 + 历史 + 多模态 + 异常
2. **设计"AI 代码助手"在 Monaco / CodeMirror 中的集成**：补全 + Inline Diff + 多文件编辑
3. **设计"AI 搜索"流式结果页**：摘要流 + 引用卡片 + 追问
4. **设计"多 Agent 工作台"前端**：任务编排 / 实时进度 / 工具调用可视化
5. **设计"离线优先的端侧 AI 笔记"**：本地向量库 + 端侧 LLM + 同步策略
6. **设计"AI 编程教育平台"**：代码沙箱 + 实时提示 + 分步引导

> 答题要点：能讲出**关键决策的取舍**（为什么选 SSE 不选 WebSocket、为什么用虚拟列表、为什么上 WebGPU 不用 WebNN），比"画一个架构图"更重要。

---

## 八、不怎么会问、可以略过

- Transformer 公式逐项推导
- 训练数据预处理细节
- 分布式训练（Megatron / DeepSpeed）框架内部
- 各种 Loss 函数的数学证明

> 反而是 **GPU 内存计算、KV Cache 估算、量化前后体积** 这种"工程估算"题会冒出来。

## 备战清单（按性价比排序）

| 优先级 | 投入 | 回报 |
|---|---|---|
| ⭐⭐⭐ | 做一个能跑的"AI 对话 + 流式 + Markdown 渲染 + 取消"的 demo | 几乎必考 |
| ⭐⭐⭐ | 用 Cursor 或 Claude Code 重构一个老项目，准备好讲"我怎么做 Code Review" | 字节 / 美团必问 |
| ⭐⭐⭐ | 跑通一次 MCP（本地 MCP Server + Cursor / Claude Desktop） | 2026 高频题 |
| ⭐⭐ | 跑通一次 WebLLM 加载 1B~3B 模型（Chrome 128+） | 端侧题加分 |
| ⭐⭐ | 读一篇 RAG / Agent 的开源仓库源码（LangChain / LlamaIndex / Dify） | 设计题素材 |
| ⭐ | 了解国产模型 API 差异（通义 / 文心 / 混元 / DeepSeek / Kimi） | 国内大厂必聊 |
| ⭐ | 记一下提示词注入 + C2PA + 国内合规 | 加分项 |

---

## 一句话总结

> **2026 大厂前端面试的 AI 题，考察的不是"你懂多少大模型"，而是"你能不能把 AI 工程化地塞进产品里 + 你平时用不用 AI 写代码"。**
> 能讲清楚一次真实的"流式 + RAG + MCP"或"端侧 LLM"项目经历，比背 100 道八股强十倍。
