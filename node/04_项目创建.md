# 一、项目创建方式
  ### 1.1 
  ```js
    -  npm i -g express-generator
    - express -e 项目名称
    - npm i
    - npm i nodemon
    "scripts": {
      "start": "nodemon ./bin/www"
    }
    - docker桌面安装
    - docker -setting配置镜像
    - 项目添加docker-compose.yml
    - docker添加mysql镜像
  ```
  ### 1.2 sequelize
  #### 项目使用步骤
    ```js
      // npm i sequelize-cli
      // npm i sequelize mysql2
      // sequelize init
      // sequelize model:generate --name Article --attributes title:string,content:text,建立模型和迁移文件
      // sequelize db:migrate：运行迁移，生成数据表
      // sequelize seed:generate --name article:新建种子文件
      // sequelize db:seed --seed XXX-article:运行种子文件，将数据填充到数据表中
    ```
  #### 文件夹介绍
    - migrations:迁移文件
    - models:模型文件
    - seeders:种子文件
